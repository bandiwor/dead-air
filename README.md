# МЁРТВЫЙ ЭФИР

Мобильный 3D-хоррор-шутер на выживание для браузера (горизонтальный экран, два стика).
Всё — код: ни одной картинки, ни одного звукового файла. Любой ассет можно заменить файлом.

## Запуск

```bash
npm install --ignore-scripts
npm run dev        # http://localhost:5173 (и по сети — для телефона)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # раздача dist/ (с CSP и Service Worker)
npm test           # 138 тестов: симуляция, три ночи, сценарий, контент, текстуры, сохранения, достижения
```

Для теста на телефоне: `npm run dev` выводит адрес в локальной сети. Откройте его на телефоне, коснитесь экрана (включится звук и полноэкранный режим), поверните горизонтально. Лучше в наушниках.

**ПК:** WASD — движение, мышь — прицел, ЛКМ — огонь, E/Space — действие, Q/колесо — оружие, G — шашка, R — перезарядка, Esc — пауза.
`?debug` в адресе открывает `window.__game` для консоли и автотестов.

## Режим отладки

**Настройки → Режим отладки: ВКЛ.** В игре появляется кнопка **DBG** (на ПК ещё `` ` `` или `F1`):

| Раздел | Что есть |
|---|---|
| Читы | бессмертие, бесконечные патроны, заморозка врагов, всё оружие, здоровье/рассудок |
| Время | пауза симуляции, шаг на 1 тик, скорость ×0.25…×4, +30 с, к следующей волне, рассвет |
| Мир | убить всех, мёртвый эфир / вернуть эфир, открыть все двери, скример сейчас |
| Существа | заспавнить перед собой любое существо |
| Телепорт | площадь, радиоузел, пристань, Щель, внутрь любого дома |
| Вид | линии коллизий и зон, оверлей статистики, камера дальше, скрыть HUD |
| Сюжет | показать карточку бестиария, сбросить бестиарий, открыть все ночи, начать любую ночь |

Оверлей: FPS, время кадра, внутреннее разрешение, draw calls, треугольники, шейдеры, текстуры,
время ночи, волна, враги по типам, эфир, напряжение, время до следующей пугалки, здоровье, рассудок,
дом, объект в фокусе, позиция; в панели — все флаги сценария. Читы переносятся в новую ночь.

## Установка как приложение

В меню через пару секунд всплывает окошко «Установить игру» (не чаще раза за запуск; «Позже» — через 3 дня, «Не предлагать» — навсегда).
На Android/Chrome кнопка вызывает системный диалог, на iPhone показывается инструкция «Поделиться → На экран „Домой“».
То же — строкой в настройках. PNG-иконки для манифеста растеризуются из `public/icon.svg`: `node scripts/make-icons.cjs`.

## Публикация и обновления

Каждый push в `main` запускает `.github/workflows/deploy.yml`: тесты, сборка, выкладка на GitHub Pages
(`https://bandiwor.github.io/dead-air/`). Один раз включите в репозитории:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.

При сборке рядом с игрой кладётся `version.json` с SHA коммита. Игра проверяет его при запуске,
каждые 5 минут и при возвращении во вкладку. Если вышла новая версия, в меню (не посреди боя)
появляется окно «Доступно обновление». В **Настройках** есть строка «Обновления»: ручная проверка
и номер версии.

## Где что менять

| Что | Где |
|---|---|
| Волны, награды, реплики ночи | `src/content/night1.ts`, `night2.ts`, `night3.ts` |
| Достижения (условия, иконки, редкость) | `src/content/achievements.ts`, `src/app/achievements.ts` |
| Тексты (i18n) | `src/i18n/ru.ts` |
| Оружие | `src/content/weapons.ts` |
| Враги (параметры) | `src/content/enemies.ts`, поведение — `src/sim/enemies.ts` |
| Пугающие биты Режиссёра | `src/content/scares.ts` |
| Кат-сцены | `src/app/cutscene.ts` |
| Замена текстуры/звука файлом | `src/content/assets.ts` (`{ file: 'assets/...' }`, файл — в `public/assets/`) |
