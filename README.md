# МЁРТВЫЙ ЭФИР

Мобильный 3D-хоррор-шутер на выживание для браузера (горизонтальный экран, два стика).
Всё — код: ни одной картинки, ни одного звукового файла. Любой ассет можно заменить файлом.

## Запуск

```bash
npm install --ignore-scripts
npm run dev        # http://localhost:5173 (и по сети — для телефона)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # раздача dist/ (с CSP и Service Worker)
npm test           # 96 тестов: симуляция, сценарий, контент, текстуры, сохранения
```

Для теста на телефоне: `npm run dev` выводит адрес в локальной сети. Откройте его на телефоне, коснитесь экрана (включится звук и полноэкранный режим), поверните горизонтально. Лучше в наушниках.

**ПК:** WASD — движение, мышь — прицел, ЛКМ — огонь, E/Space — действие, Q/колесо — оружие, G — шашка, R — перезарядка, Esc — пауза.
`?debug` в адресе открывает `window.__game` для консоли и автотестов.

## Тесты

| Файл | Что проверяет |
|---|---|
| `tests/content.test.ts` | волны, ссылки сценария, тексты в локали, досягаемость записок, мебель внутри стен, двери, деревья |
| `tests/textures.test.ts` | каждая текстура детерминирована, не плоская и **без шва при повторе** |
| `tests/collision.test.ts` | коллизии, лучи, двери, стены, рельеф, ровные площадки под домами |
| `tests/mechanics.test.ts` | оружие, взрывы, игрок, рассудок, бобина, поведение каждого врага, Режиссёр, сценарный движок |
| `tests/story.test.ts`, `tests/night2.test.ts` | сценарии ночей: дом у колодца, стук, зеркало, пристань, лампа, Невидевшие |
| `tests/nights.test.ts` | обе ночи целиком до рассвета ботом, детерминизм полного прогона |
| `tests/storage.test.ts` | настройки, прогресс и `version.json` при мусорных данных |

Посмотреть текстуры глазами (плитка 2×2, видно швы):

```bash
DUMP_TEXTURES=./tex npx vitest run tests/textures.test.ts
```

## Публикация и обновления

Каждый push в `main` запускает `.github/workflows/deploy.yml`: тесты, сборка, выкладка на GitHub Pages
(`https://bandiwor.github.io/dead-air/`). Один раз включите в репозитории:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.

При сборке рядом с игрой кладётся `version.json` с SHA коммита. Игра проверяет его при запуске,
каждые 5 минут и при возвращении во вкладку. Если вышла новая версия, в меню (не посреди боя)
появляется окно «Доступно обновление». В **Настройках** есть строка «Обновления»: ручная проверка
и номер версии.

## Где что менять

| Что | Где |
|---|---|
| Волны, награды, реплики ночи | `src/content/night1.ts` |
| Тексты (i18n) | `src/i18n/ru.ts` |
| Оружие | `src/content/weapons.ts` |
| Враги (параметры) | `src/content/enemies.ts`, поведение — `src/sim/enemies.ts` |
| Пугающие биты Режиссёра | `src/content/scares.ts` |
| Кат-сцены | `src/app/cutscene.ts` |
| Замена текстуры/звука файлом | `src/content/assets.ts` (`{ file: 'assets/...' }`, файл — в `public/assets/`) |

Документы: [`docs/GDD.md`](docs/GDD.md) — дизайн и сюжет, [`docs/TECH.md`](docs/TECH.md) — архитектура.
