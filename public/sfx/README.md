# Живые записи (необязательно)

Все звуки игры процедурные. Любой из них можно заменить записью: положите файл
(`.ogg`, `.mp3`, `.wav`, `.m4a`, `.webm`) в эту папку и впишите его в `manifest.json`
под id звука из `src/content/assets.ts`. Несколько файлов — несколько вариаций.

Самые заметные кандидаты:

| id        | что это                                 |
|-----------|-----------------------------------------|
| `shriek`  | крик скримера (высокий, пронзающий)     |
| `scream`  | крик в сценах                           |
| `choir`   | Хор в Щели                              |
| `whisper` | шёпот шептунов                          |

```json
{
  "shriek": ["shriek-1.ogg", "shriek-2.ogg"],
  "choir": ["choir-1.ogg"]
}
```

Если файла нет или он не декодируется, играет процедурный звук. Берите только записи
с лицензией, разрешающей такое использование (например CC0), и указывайте источник здесь.
