# МЁРТВЫЙ ЭФИР — техническая архитектура (v0.2, как реализовано)

## 1. Стек и решения

| Решение | Почему | Что отличается от v0.1 |
|---|---|---|
| **TypeScript strict**, Vite | Типы, быстрая сборка | — |
| **Three.js, WebGL2** | Лёгкий, полный контроль шейдеров | WebGPU не нужен на этом этапе |
| **Одна рантайм-зависимость** (`three`) | Безопасность цепочки поставок, размер | Zod и bitECS не понадобились: валидация ручная, пулы объектов вместо ECS |
| **Симуляция отдельно от рендера** | Тесты в Node, детерминизм, реплеи | — |
| **Фиксированный шаг 60 Гц** | Без интерполяции, плавно на 60 Гц-экранах | Было 30 Гц + интерполяция: проще и надёжнее так |
| **Сид-детерминизм** | Один сид и один ввод дают одно и то же состояние (тест) | — |
| **Процедурные текстуры на CPU** (64–128 px) | Генерируются за миллисекунды, легко отлаживать, легко заменить файлом | Вместо GPU: при таких размерах CPU быстрее, чем компиляция шейдеров |
| **Процедурный звук: запекание в OfflineAudioContext** + живые слои на нативных узлах | Ноль файлов, ноль нагрузки в игре | AudioWorklet не понадобился |
| **Без сервера**, PWA | Минимум поверхности атаки | — |

**Размер:** весь игровой код ≈ 190 КБ gzip, ассетов 0. **Загрузка:** ≈ 1.5–2 с (запекание ~70 вариаций звуков и 11 текстур).

## 2. Слои (`src/`)

```
core/       RNG (sfc32), математика                         — ни от чего не зависит
proc/       шум, рельеф, раскладка деревни, генераторы текстур — чистые функции
content/    данные: оружие, враги, ночь, страшилки, манифест ассетов
i18n/       локали (ru), функция t()
sim/        World + игрок, враги, бой, коллизии             — без DOM/three/audio
director/   Режиссёр страха (волны, ритм, биты, награды)   — детерминирован
narrative/  биты сюжета (условие → реплики)
render/     three: мир, существа (GPU-анимация), эффекты, пост-обработка
audio/      DSP-блоки, рецепты звуков, движок, живые слои и радиовальс
platform/   ввод (стики/кнопки/клавиатура/мышь), нативность, хранилище
ui/         HUD и экраны (DOM, только textContent)
app/        корень композиции, события sim → звук/эффекты/HUD, кат-сцены
```

Правило: `sim`, `director`, `narrative` не импортируют `render`, `audio`, `ui`, `platform`. Это проверяется тестом: `tests/determinism.test.ts` гоняет ночь в Node.

## 3. Симуляция

- `World.step(input, 1/60)` обрабатывает эфир, игрока, Режиссёра, врагов, снаряды, ракеты, бочки и сюжет.
- **События** (`shot`, `kill`, `explosion`, `line`, `scare`, …) пишутся в предвыделенный буфер. Слой представления читает их и превращает в звук, эффекты, вибрацию и HUD.
- **Отголосок:** кольцевой буфер следа игрока (отсчёт каждые 0.12 м). Отголосок — это позиция `trail[N − delay]`: он движется только когда движетесь вы.
- **Коллизии:** деревья лежат кругами в равномерной сетке, дома — OBB. Лучи для стрельбы, света фонаря и снарядов.
- **Хеш состояния** проверяет детерминизм в CI.

## 4. Подмена ассетов файлами

`src/content/assets.ts`:

```ts
// процедурно
ground:  { proc: 'ground', size: 128 },
shotgun: { proc: 'shotgun', variations: 2 },
// файлом (положить в public/assets/...)
ground:  { file: 'assets/textures/ground.png' },
shotgun: { file: ['assets/sounds/shotgun1.ogg', 'assets/sounds/shotgun2.ogg'] },
```

Код не меняется: загрузчики (`render/textures.ts`, `audio/engine.ts`) сами выбирают генератор или файл. Если звук не загрузился, игра не падает, а просто молчит в этом месте.

## 5. Рендер

**Кадр:**
1. Сцена рендерится в низкое разрешение (динамически 216–486 строк в зависимости от качества и времени кадра).
2. Пост-проход: разрывы «ленты», хроматика, тональная компрессия, раздельное тонирование, обесцвечивание по рассудку, красный при ранениях, виньетка, sRGB, зерно, квантование с Bayer-дизерингом, строки развёртки.
3. Апскейл до экрана браузером (`image-rendering: pixelated`).

**Материалы:**
- **трипланарные** (без UV) с растворением дизерингом тех деревьев и крыш, которые заслоняют игрока, и с ветром для травы и крон;
- **существа:** один draw call на тип, анимация конечностей на GPU (атрибуты опор + фазы), проявление дизерингом (без сортировки прозрачности), френелевская «фосфорная кайма».

**Свет:**
- фонарь — SpotLight с тенью (256/512/1024);
- фиксированное число точечных: столб, радиоузел, аура, вспышка ствола, 1–2 взрыва, 2 ракеты. Количество не меняется в рантайме, иначе шейдеры перекомпилируются.

**Эффекты:** пулы частиц (аддитивные и обычные), трассеры, обломки, ошмётки и гильзы с физикой, кляксы крови и копоти, кольца ударной волны.

## 6. Звук

**Рецепты** (`audio/recipes.ts`) — это графы Web Audio:
- выстрел: щелчок, тело (шум с закрывающимся фильтром), удар (синус + гармоника для динамиков), хвост и эхо от опушки, насыщение;
- шёпот: розовый шум через три форманты, слоги, фрикативы и выдох;
- голос в рупоре: пила с интонацией через форманты и полосу 500–2800 Гц с перегрузом.

**Движок:**
- мастер-лимитер, шины sfx/amb/music/ui;
- свёрточная реверберация «ночной лес» по процедурному импульсному отклику;
- позиционирование (панорама, затухание, заглушение верхов вдали), пул до 30–38 голосов;
- оглушение со звоном после взрывов; приглушение фона перед скримером.

**Живые слои** (`audio/ambience.ts`): ветер, гул, природа, сердцебиение, радиовальс. Ноты планируются с упреждением 0.4 с; при низком рассудке появляются «неправильные» ноты и сползание строя.

## 7. Мобильная «нативность»

- Полноэкранный режим и блокировка ландшафта по первому касанию (где разрешено); экран «поверните устройство» в портрете.
- Wake Lock: экран не гаснет.
- Вибрация на выстрелы, попадания, взрывы и кнопки (где есть API).
- Запрет масштабирования, pull-to-refresh, выделения, контекстного меню и двойного тапа.
- Safe-area отступы; `100%` фиксированный layout без прокрутки.
- Пауза и `AudioContext.suspend` при сворачивании; продолжение по возвращении.
- PWA: манифест (fullscreen, landscape), Service Worker (офлайн после первого запуска), иконка — SVG.
- Плавающие стики на Pointer Events, кнопки с тактильным откликом.

## 8. Безопасность

- Строгая **CSP** в production (`script-src 'self'`, без `unsafe-inline`/`eval`, `object-src 'none'`, `base-uri 'none'`).
- Никакого `innerHTML`: UI собирается через `textContent`.
- Настройки из `localStorage` проходят проверку типов и диапазонов; повреждённые данные заменяются значениями по умолчанию.
- Одна рантайм-зависимость с закреплённой версией; `npm install --ignore-scripts`.
- Нет сети, аналитики и трекеров.

## 9. Производительность

- Ноль аллокаций в горячих местах симуляции (пулы врагов, снарядов, событий); в рендере — пулы частиц и инстансов.
- Фиксированное число источников света; инстансинг деревьев, травы, камней и существ; слияние статики по материалам.
- Динамическое разрешение по времени кадра; три пресета качества (автовыбор по `deviceMemory`/ядрам).

## 10. Тесты и проверки

- `npm test`: детерминизм (два прогона с одним сидом дают одинаковый хеш, разные сиды — разный), прогон 200 с ночи без исключений, RNG.
- `npm run build`: проверка типов и сборка.
- Ручная/скриптовая проверка в Chromium (Playwright): загрузка, кат-сцена, бой, взрывы, смерть, поздние волны, скример. Ошибок в консоли нет.
